# pdf_structure_splitter

把 PDF 按**双面打印纸**为单位，拆成「彩色件」和「黑白件」两个文件 ——
让彩色页送去彩色打印机、黑白页送去黑白打印机，
**避免为了几页彩色而整本用彩色打印**。

图形界面（PySide6）+ 命令行两用，可直接打印或导出。

---

## 这个项目解决什么问题

毕业论文、学位论文、报告类文档在**制本打印**时有个很现实的问题：
整本几百页里往往只有几十页含彩色（插图、曲线图、彩照），
但送去打印店时要么整本按彩色计价、要么得人工翻找彩色页去分拣。

本项目把这个分拣过程自动化：识别哪些页需要彩色打印、哪些可以走黑白，
并按**双面打印纸**为单位拆成两个文件 ——
**彩色的钱只花在该花的地方**。

主要面向**结构比较简单的 PDF**：Word / LaTeX 导出的论文与报告
（文字 + 矢量图 + 位图）、含插图的学术文档、扫描件。
一页上同时有文字、矢量图和位图的混合内容也能正确处理。

> **不适用**：纯矢量艺术设计稿、CAD 图纸、需要色彩管理的印刷品 ——
> 这类文档的"彩色"往往是设计本身的一部分，不适合自动判断。

### 双面规则

双面打印时，一张纸有正反两面。正面黑白、反面彩色时，
这张纸**只能整张送去彩色打印机**，否则会被拆到两台打印机上。

```
只要一张纸的任意一面是彩色页  →  整张纸归入彩色件
两张纸两面都是黑白            →  整张纸归入黑白件
```

程序自动完成分类，并给出双区缩略图供**人工复核**：分错了就拖过去。

---

## 识别策略：先看结构，再决定要不要渲染

大多数做法会把**每一页都渲染成位图**再统计彩色像素。这有两个代价：
纯文字页被白白渲染；彩色内容被大片留白稀释后，小面积彩色容易漏掉。

本项目**先读页面结构，只在必要时才渲染**：

```
① 整页无图形元素（纯文字 / 空白）  →  直接判黑白，零渲染
② 有矢量图形  →  颜色已写在 PDF 里，直接读出来  →  零渲染
③ 有位图图片  →  只渲染【图片所在区域】统计色彩
                 ├─ 检出彩色 → 彩色
                 └─ 其实是灰度 → 回落黑白
```

**更快**：实测一份 132 页的论文只有 8 页需要渲染，检测约 1.1 秒。

**更准**：位图页也只渲染图片区域而非整页，色度统计的分母从
"整页像素"变成"图形区域像素"，小面积彩色不再被留白稀释：

```
整页口径：0.0007  → 低于阈值，判成黑白（漏检）
区域口径：0.0066  → 高于阈值，判彩色（正确，差 9 倍）
```

## 安装与运行

需要 **Python 3.11+**（Windows x64）。

```powershell
python -m pip install -r requirements.txt
python main.pyw                     # 启动界面
python main.pyw D:\some\file.pdf    # 也可以直接传入 PDF
```

| 依赖 | 用途 |
| --- | --- |
| `PyMuPDF` | 读写 PDF、读页面结构、渲染图形区域 |
| `numpy` | 颜色像素统计 |
| `PySide6` | 图形界面（Qt6） |

## 怎么用

1. 点 **打开 PDF**（`Ctrl+O`），程序在后台逐页检测
2. 缩略图分左右两区显示：**左 = 黑白区**，**右 = 彩色区**
3. **人工复核**：分错了就把卡片拖到另一侧
4. 点 **导出**（`Ctrl+E`）得到两个 PDF，或 **打印**（`Ctrl+P`）直接送打印机

### 卡片底部的色带 = 判定依据

| 色带 | 依据 | 含义 |
| --- | --- | --- |
| 最浅灰 | `纯文字` | 整页只有文字，未渲染直接判黑白 |
| 浅灰 | `黑白矢量` | 有表格线 / 线条图，矢量颜色为灰 |
| 中灰 | `位图灰度` | 渲染图片区域后确认无彩色 |
| **深红** | **彩色矢量** | PDF 声明颜色，结论最确定 |
| **橙** | **位图彩色** | 位图区域检出彩色像素 |

> 深红与橙的区分对复核很有用：矢量彩色是确定结论，位图彩色是像素统计的
> 结果、可能受阈值影响。鼠标悬停卡片可看到每页的判定依据与元素构成。

### 参数

| 参数 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 检测 DPI | 50–200 | 75 | 只用于位图/渐变区域的渲染 |
| 色度阈值 | 0–60 | 15 | 矢量颜色与像素色度共用 |
| 彩色占比 | 0.0000–0.0200 | 0.0010 | 只对渲染出的图形区域生效 |

改完参数要点「**重新检测**」才生效（滑块不会自动触发）。

### 检测模式与快捷键

**严格双面模式（默认）**：拖动单位是「一张纸」，同一张纸的两页永远一起走 ——
由数据结构保证，不可能把一张纸拆到两台打印机。

**单面模式**：每一页独立判定，适合只打单面、或希望彩色页尽量少印的场景。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+O` / `Ctrl+E` / `Ctrl+P` | 打开 / 导出 / 打印 |
| `F1` | 打开帮助 |
| `←` / `→` | 把选中的纸搬到黑白区 / 彩色区 |
| `Ctrl+A` / `Ctrl+点击` | 全选 / 多选卡片 |
| `Delete` | 复位到检测的原始结果 |
| `空格` / 双击 | 打开预览大图 |
| `Ctrl+滚轮` | 缩放缩略图（60%–300%） |
| 右键卡片 | 拆分为单页 / 合并回一张纸 / 预览 |

## 输出与打印

| 输出 | 内容 |
| --- | --- |
| `<名>_color.pdf` | 归属彩色的整张纸（每张纸两面都在，保持原始顺序） |
| `<名>_bw.pdf` | 归属黑白的整张纸 |
| `<名>_report.csv` | 逐页检测报告 —— **默认不输出**，需勾选「输出CSV报告」 |

输出 PDF **原样复制页面对象**（不重新渲染、不重新编码），
保留原始分辨率、文字层、矢量内容与页面尺寸。

**打印**：为彩色件与黑白件各选一台打印机，两个任务**同时**提交。
彩色/灰度是显式声明的（黑白件默认走灰度，避免驱动按彩色渲染浪费彩粉），
打印画质默认 300 dpi。

> ⚠️ 虚拟打印机（Microsoft Print to PDF 等）要先选保存位置，
> 否则 `QPrinter.begin()` 会阻塞数秒、界面无响应。


## 打包成单文件 exe

```powershell
.\build.bat
```

产物：`dist\pdf_structure_splitter.exe`（单文件，约 75 MB）。

> ⚠️ `build.spec` 里的 `hiddenimports` **必须显式声明 `pymupdf` 和 `fitz`**：
> PyMuPDF 内部用动态导入，PyInstaller 的静态分析经常漏掉，
> 漏了的话打包能成功、但**一启动就崩**。

exe 内置 `--selftest`：不显示界面，跑完整流程并用**退出码**表示成败 ——
这能查出"窗口能开、但 fitz/numpy 其实有问题"这类隐性故障。

```cmd
pdf_structure_splitter.exe --selftest D:\some\file.pdf D:\out
echo 退出码=%ERRORLEVEL%
```

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 为什么有些页没有渲染 | **正常**：纯文字页直接判黑白，彩色矢量页直接读声明颜色 |
| 调了「彩色占比」但某页判定没变 | 若那页是彩色矢量页或纯文字页，该参数对它无效 —— 只能用「色度阈值」放宽 |
| 纯文字页上的红色标题被判成黑白 | **有意如此**：整页无图形即判黑白，不看文字颜色 |
| 扫描件被误判成彩色 | 调高「色度阈值」（15 → 20–25）：位图的压缩伪影色度多在 16–20 |
| 彩色页被判成黑白 | 调低「色度阈值」；若那页只有位图，也可调低「彩色占比」 |
| 拖了滑块但结果没变 | **设计如此**：改完参数要点「重新检测」 |
| 某些页显示灰色虚线故障卡 | 该页渲染失败，状态栏与报告中会标注，不会被静默忽略 |
| 黑白件打印出来是彩色 | 打印对话框里勾上「灰度输出」；默认已勾选 |
| 导出后没有 CSV 文件 | **默认不输出**。需要就勾上「输出CSV报告」 |

---

## 不做什么

- 不做 PDF 内容编辑（增删页、旋转、批注）
- 不做多文件批量处理 / 云同步
- 仅中文界面
- **不检测文字颜色**（红色标题不会让该页判成彩色）
